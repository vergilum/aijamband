# Architecture

## Назначение

Проект является статически-ориентированным лендингом для продажи услуг ведущего Алексея Иванова и кавер-группы «Джем-Бэнд» на новогодние корпоративы и другие мероприятия в Альметьевске и Татарстане.

## Основные решения

- Используется Next.js App Router с TypeScript.
- Включен `output: "export"`, чтобы проект можно было собрать как статический сайт.
- Backend API на первом этапе отсутствует.
- Коммерческий контент вынесен из компонентов в `src/content/landing.ts`.
- Контакты, навигация и SEO-конфигурация вынесены в `src/config/site.ts`.
- Типы контента описаны в `src/types/content.ts`.
- Медиа хранятся в `public/images` и `public/videos`, а их описание находится в content-модели.
- UI-компоненты читают готовые данные и не содержат цен, телефонов, рекламных утверждений или отзывов, которые должны редактироваться как контент.

## Ограничение по персональным данным

Проект сознательно не содержит формы обратной связи и собственной обработки данных посетителей. Контакт осуществляется переходом во внешние сервисы связи.

На сайте не создаются:

- формы заявки;
- поля имени, телефона или email;
- endpoint `POST /lead`, `POST /contact`, `POST /callback` или аналоги;
- базы данных посетителей;
- CRM;
- собственный онлайн-чат;
- авторизация или аккаунты посетителей.

Также не подключаются Google Analytics, Яндекс Метрика, рекламные пиксели, cookie-based analytics или fingerprinting.

## Контентная модель

Ключевые структуры:

- `siteConfig` — исполнитель, группа, регион, города, известные публичные ссылки.
- `contacts` — внешние каналы связи. Если `href` отсутствует, кнопка не отображается.
- `navigation` — якорная навигация лендинга.
- `hero` — первый экран.
- `host` — блок ведущего.
- `band` — блок кавер-группы.
- `servicePackages` — пакеты, цены и CTA.
- `media` — изображения и видео, включая poster, category, sortOrder и placeholder-флаг.
- `reviews` — реальные отзывы или пустой массив до подтверждения.
- `faq` — вопросы и ответы.
- `seo` — title, description, keywords, Open Graph и canonical-ready base URL.

## Видео

Видео моделируется через `MediaItem` с `type: "video"`, `src`, `poster`, `title`, `description` и `placeholder`.

Если `src` отсутствует, компонент показывает placeholder-плеер. Это позволяет сохранить layout и не загружать тяжелые видео до добавления финальных файлов.

## SEO

SEO реализовано через Next.js metadata API в `src/app/layout.tsx`, а также `src/app/robots.ts` и `src/app/sitemap.ts`.

Поле `seo.siteUrl` использует production-домен `https://aijamband.ru` через `src/lib/paths.ts` и переменную `NEXT_PUBLIC_SITE_URL` в GitHub Pages workflow.

## Что не добавлено намеренно

- CMS и admin panel.
- База данных.
- API routes.
- Analytics/tracking.
- UI-библиотеки.
- Docker-инфраструктура.
- Вымышленные отзывы, клиенты, статистика и контакты.
