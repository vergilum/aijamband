# Алексей Иванов и Джем-Бэнд

Коммерческий лендинг для ведущего мероприятий Алексея Иванова и кавер-группы «Джем-Бэнд». Первый этап проекта: технический фундамент, структура контента, SEO-база и семантический каркас страницы.

## Стек

- Next.js 16 App Router
- React 19
- TypeScript
- CSS без UI-библиотек
- Static export через `output: "export"`

## Запуск локально

```bash
npm install
npm run dev
```

## Production build

```bash
npm run typecheck
npm run lint
npm run build
```

Статический результат сборки формируется в `out/`.

## Где менять контент

- Основной контент лендинга: `src/content/landing.ts`
- Типы контента: `src/types/content.ts`
- Конфигурация сайта, навигация, контакты и SEO: `src/config/site.ts`

## Где менять цены

Цены находятся в `src/content/landing.ts` в массиве `servicePackages`.

Для каждого пакета доступны поля `price`, `pricePrefix`, `priceSuffix`, `showPrice` и `priceFallbackText`. Если `showPrice` равен `false`, frontend показывает fallback-текст из контента.

## Где менять контакты

Контакты находятся в `src/config/site.ts` в массиве `contacts`.

Если `href` равен `null`, соответствующая кнопка не отображается. Кнопки являются обычными ссылками на внешние сервисы или `tel:` и не отправляют данные на сервер.

## Где добавлять фотографии

Файлы для сайта следует размещать в `public/images/`. Временные изображения лежат в `public/images/placeholders/` и явно помечены как placeholder.

После добавления файла нужно обновить массив `media` в `src/content/landing.ts`.

## Где добавлять видео

Видео можно размещать в `public/videos/`. Для каждого видео желательно подготовить poster-изображение в `public/images/` и добавить объект `MediaItem` в `src/content/landing.ts`.

Текущий прототип не загружает реальные видео на первом экране и не использует autoplay.

## Персональные данные

Проект сознательно не содержит:

- форм обратной связи;
- API routes для лидов или контактов;
- базы данных;
- регистрации и авторизации;
- собственной аналитики;
- tracking scripts, pixels, cookie-based analytics и fingerprinting.

Контакт осуществляется переходом во внешние сервисы связи. Сайт не сохраняет персональные данные посетителя в приложении.
